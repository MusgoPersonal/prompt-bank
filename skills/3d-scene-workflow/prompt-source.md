TEMPLATE WEB INMERSIVA (PROMPT REUTILIZABLE)
============================================

Como usar esta plantilla:
1. Recibir el brief de la empresa (rubro, producto, datos, colores, CTA).
2. Reemplazar cada (placeholder) por el dato concreto del brief.
3. Adaptar las atmosferas y el estado del protagonista a la industria.
4. Pasar el prompt final al agente para construir la web completa.

GUIA DE ADAPTACION POR INDUSTRIA
---------------------------------
- Aerolinea: avion | suspendido/rodando/despegando/vuelo/crucero/descenso/aterrizaje | noche, amanecer, hangar, atardecer
- Gastronomia: plato/mesa | reposo/preparacion/emplatado/servir | cocina, mantel, luz calida
- Hotel/Real estate: edificio/suite | exterior/lobby/habitacion/vista | dia, atardecer, noche urbana
- Auto/Movilidad: vehiculo | estatico/arranque/carretera/ciudad | garage, montana, tunel
- Fitness/Salud: cuerpo/atleta | reposo/calentamiento/esfuerzo/descanso | gym, outdoor, amanecer
- SaaS/Tech: orbe/UI digital | boot/flujo de datos/red global | espacio digital, datos
- Moda/Lujo: prenda/accesorio | concepto/detalle/pasarela | estudio, oscuridad elegante

PROMPT FINAL
============

Actua como un director creativo digital, disenador de experiencias inmersivas, director de arte y desarrollador Frontend Senior especializado en experiencias web premium, sitios Awwwards, Three.js, React Three Fiber, GSAP y animacion cinematografica.

Tu objetivo es crear una web completamente funcional, visualmente impresionante y de nivel profesional para:

(nombre de empresa)

Tagline:

"(tagline de la marca)"

No quiero una landing page tradicional. No quiero una pagina SaaS. No quiero bloques repetitivos. No quiero una plantilla.

Quiero una experiencia inmersiva donde el usuario sienta que esta realizando un viaje completo. Debe parecer una mezcla entre Apple, SpaceX, Porsche, Emirates, Lexus, Nothing, Bruno Simon y las mejores webs premiadas en Awwwards.

Toda la experiencia debe desarrollarse alrededor de un (producto u objeto protagonista) 3D elegante, moderno y futurista. Sera el protagonista absoluto. Durante todo el scroll el usuario lo acompanara mientras atraviesa distintas escenas. La camara debera moverse de forma cinematografica. Cada seccion debera sentirse como una escena diferente de una pelicula. Todo debe transmitir innovacion, lujo y tecnologia.

CONCEPTO GENERAL
----------------
El scroll controla toda la narrativa. El usuario nunca cambia de pagina. Todo ocurre dentro de una unica experiencia continua. A medida que el usuario hace scroll: el protagonista cobra vida, cambia de posicion, la camara gira, aparecen efectos atmosfericos, cambia la iluminacion, aparecen datos flotantes, graficos, particulas y nuevas escenas. Cada transicion debe sentirse completamente natural. Nunca deben existir cortes bruscos.

ESTILO VISUAL
-------------
Estetica premium (Apple, Porsche, Nothing). Paleta principal: negro profundo, (color primario de la marca), blanco, plateado, gris grafito, acentos suaves. Iluminacion elegante, cristales, glassmorphism muy sutil, bloom cinematografico, reflejos suaves, sombras realistas, ambient occlusion, profundidad de campo, HDRI, neblina volumetrica, particulas flotantes. Tipografia editorial moderna. Muchisimo espacio en blanco. Diseno limpio, elegante, minimalista, tecnologico. Nunca colores chillones, gradientes exagerados, tarjetas repetitivas ni iconos genericos.

SECCION 1 - HERO
----------------
La pagina inicia completamente oscura. Ambiente sutil. Lentamente aparecen particulas. El protagonista aparece suspendido en escena con movimiento muy suave y luces de acento encendidas. La camara realiza un travelling lento. Titulo enorme: "(nombre de empresa)". Subtitulo: "(tagline de la marca)". Texto: "(frase emocional del hero)". Boton principal: "(CTA primario)". Al mover el mouse: efecto parallax, ligera rotacion del protagonista, movimiento de particulas, desplazamiento de la iluminacion. Todo debe sentirse vivo. La entrada debe parecer el inicio de una pelicula.

SECCION 2 - ARRANQUE
--------------------
Al comenzar el scroll la camara se acerca. El protagonista cobra vida: (acciones del protagonista: encenderse, acelerar, girar, desplegarse). Las luces aumentan de intensidad. La camara cambia a un plano lateral y acompana el movimiento. Las particulas se vuelven mas intensas. Aparecen lineas de velocidad. Movimientos cinematograficos. Durante esta escena aparecen pequenos bloques informativos: (puntos clave del proceso: caracteristicas principales del producto/servicio). Cada bloque entra mediante animaciones suaves. No deben aparecer todos al mismo tiempo.

SECCION 3 - EXPLORA EL INTERIOR
-------------------------------
La camara atraviesa el protagonista. Se muestra una representacion premium del interior (puede ser conceptual). La iluminacion cambia a tonos (luz interior segun industria). Se muestran (elementos del interior: componentes, espacios, materiales). Cada elemento aparece mediante animaciones independientes. Mientras el usuario continua haciendo scroll aparecen textos como: "(textos evocativos breves: Silencio. Espacio. Tecnologia.)". Los textos aparecen mediante efectos Fade + Blur + Translate.

SECCION 4 - CATALOGO
--------------------
La camara sale al exterior. Aparece (entorno de catalogo: mapa, vitrina, ciudad, red de nodos). Las conexiones se dibujan dinamicamente y se iluminan cuando el protagonista pasa cerca. Elementos destacados: (lista del catalogo: destinos, productos, servicios, ubicaciones). Cada elemento muestra: (datos del catalogo: imagen, precio, tiempo, disponibilidad). La informacion aparece mediante paneles flotantes. Las lineas deben animarse con trazos luminosos. La camara nunca permanece completamente quieta.

SECCION 5 - DETALLE TECNICO
---------------------------
Cambio de escena. El protagonista entra en un (entorno de exposicion: hangar, estudio, laboratorio). La iluminacion se vuelve mas dramatica. La camara gira lentamente alrededor. Aparecen lineas tecnicas senalando partes. Cada linea conecta con informacion flotante: (caracteristicas tecnicas del producto). Cada especificacion aparece con animaciones tipo HUD. Los textos nunca deben saturar la pantalla. Debe sentirse como una presentacion tecnologica de alta gama.

SECCION 6 - EXPERIENCIA
-----------------------
La iluminacion cambia a un ambiente calido y elegante. El protagonista continua su recorrido. Cada beneficio aparece mediante animaciones independientes con efecto glassmorphism: (beneficios de la experiencia). Cada bloque debe aparecer con fade in, blur, elevacion suave y ligero efecto de profundidad. Nunca tarjetas convencionales. Todo debe parecer parte del escenario.

SECCION 7 - TECNOLOGIA / DATOS VIVOS
------------------------------------
La escena cambia completamente. El fondo se vuelve oscuro. El protagonista queda suspendido en un espacio digital. Comienzan a aparecer interfaces holograficas, HUD futuristas, graficos dinamicos, paneles transparentes, animaciones de datos: (datos vivos simulados: metricas, estado, velocidad, consumo). Toda la informacion debe actualizarse mediante animaciones continuas. Los graficos deben sentirse vivos. Inspiracion: aviacion moderna, ciencia ficcion elegante, interfaces de Iron Man, HUD aeronauticos, Apple Vision Pro.

SECCION 8 - VALORES
-------------------
La escena cambia hacia una atmosfera de calma y luz. El protagonista atraviesa un entorno (entorno inspirador: amanecer, oceano, montanas). Explicar visualmente: (valores de la empresa: sostenibilidad, compromiso, mision). No utilizar grandes parrafos. Usar pequenas frases inspiradoras. Mientras tanto aparecen rayos volumetricos, particulas y elementos naturales lejanos. Todo debe transmitir calma, elegancia, innovacion.

SECCION 9 - ESTADISTICAS
------------------------
El protagonista entra en un tunel formado por datos luminosos. Aparecen enormes numeros animados con counter: (datos reales de la empresa: clientes, anos, paises, satisfaccion). Las cifras deben integrarse dentro del recorrido, no como seccion convencional. El fondo continua completamente animado. Las particulas reaccionan al movimiento del scroll. Las lineas de velocidad acompanan la sensacion de avance. Cada transicion debe conectar naturalmente con la siguiente escena.

SECCION 10 - CONVERSION
-----------------------
Despues de atravesar el tunel de datos, el protagonista comienza a desacelerar. La camara cambia de perspectiva. Aparece (entorno de llegada: ciudad, local, sala). El protagonista se detiene suavemente. En ese momento aparece la interfaz de conversion. No debe parecer un formulario tradicional. Panel premium con efecto cristal. Campos: (campos del CTA segun negocio: origen/destino/fecha - o nombre/email/producto - o fecha/hora/servicio). Opciones: (variantes del producto/servicio). Boton principal: "(texto del boton final)". El boton debe tener una microinteraccion elegante al pasar el cursor.

SECCION 11 - CTA FINAL
----------------------
Despues del formulario, la camara vuelve a alejarse. El protagonista reaparece detenido en escena nocturna. Las luces de acento parpadean suavemente. La camara comienza lentamente a elevarse. El protagonista retoma su movimiento. La camara continua alejandose. La niebla cubre lentamente la escena. Aparece el mensaje final: "(mensaje final de marca, en mayusculas)". Debajo: "(nombre de empresa)" y un boton: "(CTA secundario: Explorar catalogo)". Las particulas comienzan lentamente a desaparecer. La musica ambiental se desvanece. La experiencia termina con una transicion elegante hacia negro.

DIRECCION DE ANIMACION
----------------------
El scroll debe ser el principal controlador de la narrativa. Utilizar: GSAP, GSAP ScrollTrigger, Lenis, React Three Fiber, Three.js, Drei, Framer Motion. Cada seccion debe tener animaciones sincronizadas con el progreso del scroll. El protagonista debe tener diferentes estados segun la industria. La camara debe tener diferentes posiciones y focales para cada escena. Evitar movimientos bruscos. Utilizar interpolacion suave.

TECNOLOGIA 3D
-------------
Utilizar: Three.js, React Three Fiber, Drei, GLB/GLTF, HDRI, PBR Materials, GLSL Shaders, Post Processing (Bloom, Depth of Field, Ambient Occlusion, Motion Blur cuando sea apropiado), efectos volumetricos, sistemas de particulas. Si no existe un modelo 3D propio, construir uno estilizado procedural con materiales PBR, reflejos, iluminacion realista, sombras y luces de acento. No sacrificar rendimiento por exceso de poligonos.

ATMOSFERA
---------
Crear diferentes atmosferas durante el recorrido sincronizadas con el scroll: (lista de atmosferas segun industria).

RESPONSIVE
----------
Debe funcionar en desktop, laptop, tablet y mobile. En moviles reducir la complejidad del escenario 3D cuando sea necesario. Mantener la narrativa. Adaptar: posicion de camara, cantidad de particulas, resolucion de texturas, cantidad de efectos, tamano de textos, velocidad de animaciones.

RENDIMIENTO
-----------
Optimizar agresivamente: Lazy Loading, Suspense, Progressive Loading, Draco Compression, KTX2/Basis Textures, Level of Detail, Instanced Meshes, Frustum Culling, Texture Optimization, Code Splitting. Priorizar 60 FPS. Si el dispositivo tiene poca potencia, utilizar automaticamente una version visual simplificada.

ACCESIBILIDAD
-------------
Agregar: navegacion por teclado, estados focus visibles, contraste adecuado, textos alternativos, aria-labels, reduced-motion support. Si el usuario tiene activado "prefers-reduced-motion", reducir considerablemente las animaciones sin romper la experiencia.

RESULTADO FINAL
---------------
NO CREAR UNA LANDING PAGE CONVENCIONAL. Crear una experiencia narrativa. El usuario debe sentir que esta viajando dentro de una pelicula interactiva. El protagonista debe ser el centro. El scroll debe ser el mecanismo que controla el viaje. Cada escena debe aportar algo nuevo. Cada transicion debe sentirse intencional. Cada animacion debe tener un proposito.

Antes de finalizar: revisar toda la experiencia, eliminar animaciones innecesarias, eliminar elementos repetitivos, mejorar el ritmo, mejorar la jerarquia visual, optimizar el rendimiento, revisar responsive, revisar accesibilidad, revisar coherencia visual, revisar todas las transiciones.

El resultado debe sentirse como una experiencia digital premium de nivel Awwwards, FWA, CSS Design Awards. No como una plantilla generada automaticamente.

Prioridad absoluta: 1. WOW visual, 2. Narrativa, 3. Fluidez, 4. Calidad 3D, 5. Interactividad, 6. Rendimiento, 7. Usabilidad, 8. Accesibilidad.

Construye la experiencia completa y funcional. No entregues solamente un mockup, componentes vacios, botones sin funcionalidad o secciones placeholder. Si una tecnologia o efecto no puede implementarse exactamente como se describe, crea la alternativa visual mas cercana manteniendo la misma intencion artistica.

El resultado debe ser una web que sorprenda al usuario desde el primer segundo y que mantenga la sensacion de descubrimiento hasta el ultimo scroll.
